Manage Docker containers on Synology from your phone

Set up Container Manager so your apps are easy to look after, then start, stop and install containers from Android or iPhone, at home or away.

Updated November 19, 2026 · by duconmang

Docker on a Synology NAS runs the self-hosted apps many people buy a NAS for: Jellyfin for media, Immich for photos, Pi-hole for ad blocking and many more. Setting them up happens in DSM's Container Manager. Checking on them later, or restarting one that has stopped, is something you often want to do from your phone.

This guide explains what you can and cannot do from a phone, how to set up containers so they are easy to manage, and how to control them day to day with NasHubs.

Before you start: does your NAS support Container Manager?

Container Manager is the DSM 7.2 name for the package that used to be called Docker. It is available on most Plus-series and many other models, but not all of them; Synology lists the supported models on the package's page in Package Center. If you can install Container Manager in DSM, NasHubs can manage its containers.

You also need a DSM account in the administrators group. Container control is an admin action in DSM, and NasHubs uses the same permissions.

Set up containers so they are easy to manage

A few habits in Container Manager pay off later, on any device:

  1. Keep app data in one shared folder. Create a docker shared folder and give each app its own subfolder, for example /volume1/docker/jellyfin. Backups and moves become one folder instead of many.
  2. Use Projects (Docker Compose) for multi-container apps. Apps like Immich need a database and a cache next to the main container. A Project keeps them together and starts them in the right order.
  3. Set a restart policy. unless-stopped brings containers back after a NAS reboot or a DSM update without you touching anything.
  4. Give containers clear names. jellyfin is easier to find on a phone screen than linuxserver-jellyfin-1.
  5. Check port clashes. DSM already uses 80, 443, 5000 and 5001. Pi-hole also needs port 53, so turn off DSM's DNS Server package or give Pi-hole its own IP address with a macvlan network.

Manage containers from your phone with NasHubs

  1. Connect to your NAS. If you have not done this yet, follow Manage your Synology NAS from your phone.
  2. Open the Apps screen. It lists your containers and installed packages with their current state.
  3. Start or stop. Tap a container to change its state. Stopping and starting again is the quick fix when a media server stops responding or an app needs a fresh start after a config change.
  4. Open the app's web page. For services with a web interface, open them straight from the list instead of typing the address and port.
  5. Install common self-hosted apps. NasHubs offers popular apps such as Jellyfin, Immich and Pi-hole, set up on the NAS in a few taps.

Managing containers when you are away

Exposing Container Manager or the DSM login to the internet is risky. With NasHubs Agent on the NAS, commands are signed with Ed25519 over TLS with a pinned certificate and travel through Cloudflare Tunnel or Tailscale, so you can start or stop a container from anywhere without opening router ports.

What is still best done in DSM

A phone is good for checking and controlling containers. A few jobs are still easier on a larger screen in DSM's Container Manager:

  • writing or editing a Compose file for a new Project;
  • changing volume mappings, environment variables or networks;
  • reading long container logs while troubleshooting.

Set things up once in DSM, then use your phone for the day-to-day.

Updating a container safely

Most self-hosted apps update by pulling a newer image and recreating the container. Because the app's data lives in its own folder under /volume1/docker, recreating the container keeps your settings. Before a major version update, copy that folder or take a snapshot if your volume uses Btrfs, and read the app's release notes for breaking changes.

Questions

Can I run Docker on any Synology NAS?

No. Container Manager is available on many but not all models. Check whether Package Center offers Container Manager for your NAS.

Is Container Manager the same as Docker?

Yes. Container Manager is the DSM 7.2 name for Synology's Docker package, with added support for Docker Compose projects.

Do I need admin rights to manage containers from my phone?

Yes. Use a DSM account in the administrators group, the same as in DSM's Container Manager.

Can I control containers when I am not at home?

Yes, through NasHubs Agent over Cloudflare Tunnel or Tailscale, without opening ports on your router.
