Share films and photos with everyone on your NAS

NasHubs 2.2.1 lets you, the NAS administrator, install Jellyfin and Immich once and give every DSM user their own account. Who sees what follows the shared-folder permissions you already set in DSM.

Updated November 20, 2026 · by duconmang · Tiếng Việt

What changed in 2.2.1

  • Two roles. DSM administrators are Admins in NasHubs: they install, update and remove apps and manage devices. Every other DSM user is a Member.
  • Members pair with their own DSM account. No invitation code: they sign in to DSM in NasHubs and tap Connect with your DSM account. Delete or disable the DSM user and their phone is unpaired automatically.
  • Jellyfin gets its own shared folder. Installing Jellyfin creates a Jellyfin shared folder with Movies, Shows and Music. Admins can write, every DSM user can read.
  • Immich gets its own shared folder and a library per person. Uploads go to an admin-only Immich shared folder. Each DSM user's home/Photos becomes their own Immich library.
  • Accounts that follow DSM. The Agent creates a Jellyfin and an Immich account for every DSM user and keeps library access in line with DSM permissions, every 10 minutes.
  • Fixes. Large installs no longer stop with HTTP 504 behind DSM; quick setup now adds libraries to a Jellyfin that is already set up; folders are only created inside real shared folders.

Before you start

  • You are in the administrators group on a Synology NAS with DSM 7 and Container Manager.
  • User Home is turned on (Control Panel → User & Group → Advanced). Immich needs it for each person's Photos folder.
  • NasHubs 2.2.1 on your phone and the NasHubs Agent on the NAS. The app offers the Agent update itself.

Set it up as the admin

  1. Connect the Agent. Open Apps. If the Agent is not paired yet, tap Set up Agent and install it through DSM. If the app says the Agent is out of date, tap Update Agent; it takes about a minute. The Agent card should read Agent connected · Administrator.
  2. Install Jellyfin. In Discover, pick Jellyfin and tap Install. You do not need to choose a movie folder: the Agent creates the Jellyfin shared folder. Pick an existing share only if your films already live elsewhere.
  3. Finish Jellyfin's quick setup. Choose the Jellyfin admin name and password. The Movies, Shows and Music libraries are filled in for you. Member accounts are switched on at the same time.
  4. Copy your films. Put films in Jellyfin/Movies, series in Jellyfin/Shows (one folder per show) and music in Jellyfin/Music, with File Station, SMB from a computer or the File tab in NasHubs. Jellyfin scans on its own schedule; for an instant scan open Jellyfin → Dashboard → Scan All Libraries.
  5. Install Immich (optional). Install it the same way and create the Immich admin account in quick setup. The Agent creates home/Photos for every DSM user and links it as that person's Immich library. New users get theirs within 10 minutes, without restarting Immich.

Add family members

  1. Create a DSM user for each person in Control Panel → User & Group. Do not add them to administrators.
  2. They install NasHubs, add your NAS with their own DSM user name and password, and open Apps.
  3. They tap Connect with your DSM account. The Agent checks the DSM session and pairs the phone as a Member. Members only see the apps you opened to them (Jellyfin and Immich) and cannot change the Agent.
  4. They set their app password. In Jellyfin or Immich, My account → new password. They sign in to Jellyfin with their DSM user name and to Immich with username@nashubs.local.

Decide who sees what

NasHubs reads the permissions of each shared folder in DSM (Control Panel → Shared Folder → Edit → Permissions):

  • Read/Write or Read only lets a user see the Jellyfin libraries in that folder.
  • No access wins over everything else, including group permissions. Use it to hide a folder from one person.
  • Want a films folder for adults only? Create another shared folder, give read access only to the people who may watch it, then add it as a library in Jellyfin.
  • Changes reach Jellyfin within about 10 minutes.

Good habits

  • Do not give regular users access to the docker shared folder: it holds every app's settings.
  • Keep the number of DSM administrators small; each of them is an Admin in NasHubs.
  • The Agent keeps only an API key for Jellyfin and Immich, never their passwords.

Upgrading from 2.2.0

Update the app, then update the Agent from the Apps screen. If you installed Jellyfin before 2.2.1 with a movie path such as /volume1/data, open Jellyfin → Redeploy to create the Jellyfin shared folder, then Quick setup and sign in with your existing Jellyfin admin account: the missing libraries are added.

Questions

Can a member install or remove apps?

No. Only DSM administrators can install, update or remove apps, invite devices or change the Agent.

Why does a member see no Jellyfin library?

Their DSM account has no read access to the folder, or has No access on it. Check Control Panel → Shared Folder → Permissions and wait up to 10 minutes.

Where are Immich uploads stored?

In the Immich shared folder, which only administrators can open. Photos already in a person's home/Photos stay where they are and are read-only for Immich.

Do I need Synology Photos?

No. Immich only needs User Home turned on in DSM.
